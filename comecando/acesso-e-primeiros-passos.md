# Acesso e primeiros passos

Para entrar no Race Manager, use o nome de usuário e a senha fornecidos pelo responsável pela organização.

## Entrar no sistema

1. Abra o Race Manager.
2. Preencha **Usuário**.
3. Preencha **Senha**.
4. Selecione **Entrar**.

O sistema direciona cada pessoa para a área correspondente ao seu perfil.

Se a senha tiver espaços no início ou no fim, o Race Manager pede que você confirme se deseja mantê-los ou removê-los. Isso evita erros comuns ao copiar e colar uma senha.

## Primeiro acesso do organizador

Quando ainda não existe um evento ativo, o organizador é levado à lista de eventos.

- Se não houver evento cadastrado, selecione **Novo evento** e preencha os dados solicitados.
- Depois de criar o evento, selecione-o para torná-lo ativo.
- Se já existirem eventos, escolha qual deles será usado nas próximas operações.

Somente um evento pode ficar ativo por vez. Ao ativar outro evento, o evento anterior deixa de ser o evento operacional.

## Primeiro acesso de um colaborador

Gerentes de inscrições, cronometristas e narradores trabalham com o evento ativo definido pelo organizador.

Se a tela informar que não existe evento ativo, peça ao organizador para verificar a seleção do evento. O colaborador não escolhe um evento diferente por conta própria.

## Confirmar o evento antes de trabalhar

Antes de cadastrar, cronometrar ou consultar dados, confira o nome do evento mostrado na tela. Essa verificação é especialmente importante quando a organização realiza vários eventos em datas próximas.

## Recuperar a senha

A recuperação por e-mail funciona para contas que possuem um endereço de e-mail cadastrado.

1. Na tela de acesso, selecione **Esqueci minha senha**.
2. Informe seu nome de usuário.
3. Use o código de recuperação enviado por e-mail.
4. Digite o código recebido.
5. Defina e confirme a nova senha.

O cadastro atual de gerente de inscrições, cronometrista e narrador não solicita e-mail. Se você usa um desses perfis, peça ao organizador para redefinir sua senha na lista de usuários.

Se a conta deveria receber o código e ele não chegar, confirme o nome de usuário e procure o responsável pelo suporte. Não envie a senha atual durante o atendimento.

## Encerrar a sessão

Abra **Configurações** pelo ícone disponível no topo da tela. Há duas opções:

- **Sair:** encerra somente a sessão do dispositivo atual.
- **Encerrar todas as sessões:** desconecta a conta de todos os dispositivos.

Use a segunda opção quando houver suspeita de acesso indevido ou quando uma conta não deva continuar conectada em outro equipamento.

## Se o menu esperado não aparecer

Confira, nesta ordem:

1. se você entrou com o usuário correto;
2. se existe um evento ativo;
3. se o nome do evento exibido é o esperado;
4. se o seu perfil possui acesso à função;
5. se a configuração do evento permite aquela operação.

Se o problema continuar, saia e entre novamente. Caso ainda não resolva, anote a mensagem exibida e procure o responsável pelo suporte, sem enviar senhas ou dados pessoais de pilotos.
