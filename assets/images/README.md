# Imagens da documentação

Armazene neste diretório as imagens usadas na documentação pública.

Antes de adicionar uma imagem:

- use somente dados fictícios;
- remova dados pessoais, credenciais e identificadores reais;
- não mostre endereços internos ou informações de produção;
- use nomes de arquivo descritivos, em letras minúsculas e sem espaços;
- prefira o formato PNG para capturas de tela;
- inclua texto alternativo ao inserir a imagem em uma página.

Exemplo de referência:

```markdown
![Lista de eventos com um evento ativo](../../assets/images/lista-de-eventos.png)
```
