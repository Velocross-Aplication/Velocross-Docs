# Race Manager

Bem-vindo à documentação oficial do **Race Manager**, o sistema de apoio à organização e à operação de eventos de corrida.

Esta documentação foi preparada para quem trabalha diretamente no evento: organizadores, gerentes de inscrições, cronometristas e narradores. Os guias usam linguagem operacional e não exigem conhecimento técnico.

> **Versão documentada:** Race Manager 1.3.0

## O que você pode fazer no Race Manager

O sistema reúne, em um único lugar, as principais atividades de um evento:

- preparar eventos, categorias, pacotes e regras de pontuação;
- cadastrar a equipe e definir o perfil de cada usuário;
- registrar pilotos e acompanhar inscrições;
- controlar recebimentos, devoluções, descontos e cortesias;
- organizar baterias simples ou com categorias mescladas;
- registrar resultados por cronometragem ou por lançamento manual;
- acompanhar HoleShot, colocações e informações para o narrador;
- gerar relatórios do evento e consultar a classificação de Copas.

Algumas opções aparecem somente para determinados perfis, permissões ou configurações do evento.

## Por onde começar

Se este é o seu primeiro acesso, siga esta ordem:

1. Leia a [visão geral](comecando/visao-geral.md).
2. Consulte [acesso e primeiros passos](comecando/acesso-e-primeiros-passos.md).
3. Entenda os [perfis e permissões](comecando/perfis-e-permissoes.md).
4. Aprenda a [criar e configurar um evento](organizacao-do-evento/criar-e-configurar-evento.md).
5. Configure [categorias, pacotes e regras](organizacao-do-evento/categorias-pacotes-e-regras.md).
6. Veja como funcionam os [eventos ativos e históricos](organizacao-do-evento/eventos-ativos-e-historicos.md).
7. Organize os acessos em [usuários e equipe](organizacao-do-evento/equipe-do-evento.md).
8. Aprenda a [cadastrar e gerenciar inscrições](inscricoes/gerenciar-inscricoes.md).
9. Conheça o [financeiro da inscrição](inscricoes/financeiro-da-inscricao.md).
10. Saiba como trabalhar com [categorias mescladas](dia-da-prova/categorias-mescladas.md).
11. Organize a [ordem das provas e a programação do evento](dia-da-prova/ordem-e-baterias.md).
12. Use o [mapa das funcionalidades](referencia/mapa-de-funcionalidades.md) para localizar cada área do sistema.

## Como esta documentação está organizada

Os próximos capítulos serão publicados por etapas, acompanhando o fluxo real de trabalho:

1. preparação do evento;
2. usuários e equipe;
3. inscrições e financeiro;
4. operação no dia da prova;
5. resultados, relatórios e Copa;
6. dúvidas frequentes e solução de problemas.

A documentação não será preenchida com páginas curtas apenas para completar o menu. Cada novo capítulo deve apresentar um procedimento completo e validado no sistema.

## Segurança e privacidade

Os exemplos e as futuras imagens desta documentação devem usar dados fictícios. Não publique dados pessoais, credenciais, códigos de acesso, identificadores internos, endereços privados, registros de produção ou informações financeiras reais.
